# Data Science Professional Portfolio — SQL

## Project Overview

This project is a SQL-based professional portfolio database for a fictional Data Science professional.

The database stores and analyzes information related to the professional's education, technical skills, work experience, projects, certifications, and social profiles.

All personal, educational, professional, and certification data used in this project is fictional and created for demonstration purposes.

## Project Objective

The main objective of this project is to demonstrate SQL skills by designing a relational database and performing different types of data analysis using SQL queries.

## Database Structure

The database contains the following tables:

- `person` — Stores basic professional information.
- `education` — Stores educational qualifications.
- `skills` — Stores Data Science, Machine Learning, AI, programming, and other technical skills.
- `experience` — Stores internship and professional experience.
- `projects` — Stores Data Science and Machine Learning projects.
- `project_tools` — Stores tools and technologies used in each project.
- `certifications` — Stores professional certifications.
- `social_profiles` — Stores professional social profile links.
